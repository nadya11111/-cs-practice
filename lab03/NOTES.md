git giff - показывает разницу между двумя состояниями файлов, не отображая при этом историю коминтов
git show - показывает детальную информацию о конкретном коммите
git log - показывает историю комминтов
log -S - ничего не выдало потому что мы не использовали функцию "def"
git blame - показывает построчно,каким именно коммитом и каким автором была последний раз изменена каждая строка в файле
