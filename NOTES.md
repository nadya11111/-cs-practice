git giff - показывает разницу между двумя состояниями файлов, не отображая при этом историю коминтов 
git show - показывает детальную информацию о конкретном коммите 
git log - показывает историю комминтов

отличее git restire ot git restore --source=...
git restire - берет последнюю версию файла из коммита и заменяет ею текущее изменения в рабочей папке

git restore --source=...- позволяет взять версию файла из любого указанного коммита и поместить ее в рабочую папку.
