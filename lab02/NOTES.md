рабочая папка-это файл, с которым человек работает на компьютере

индекс- это область куда добавляются изменения ,которые вносятся в следующий комминт

комминт- это сохраненная версия подготовленных изменений в истории Git

git - это программа на компьютере, которая отслеживает изменения в файлах

GitHud- это сайт куда можно отправлять свои репозитории



Git status- показывает текущее состояние репозитория

git diff- показывает разницу между рабочей папкой и индексом 

git diff --staged- показывает разницу между индексом и последним коммитом



ветка - это независимая линия разработки она позволяет работать с изменениями не затрагивая основную ветку.Когда создается новый коммит в ветке -она просто двигается вперед , а другие остаются на месте.

Слияние-это объединение изменений из одной ветки в другую
