рабочая папка-это файл, с которым человек работает на компьютере

индекс- это область куда добавляются изменения ,которые вносятся в следующий комминт

комминт- это сохраненная версия подготовленных изменений в истории Git

git - это программа на компьютере, которая отслеживает изменения в файлах

GitHud- это сайт куда можно отправлять свои репозитории
